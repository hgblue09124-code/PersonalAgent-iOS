## 3. P0 Audit — Official llama.cpp

**Source Repository**: `ggml-org/llama.cpp`
**Focus Directory**: `examples/llama.swiftui/` (`llama.cpp.swift`, `LibLlama.swift`)

### Particle Analysis
1. **Model Loading (`llama_model_load_from_file`)**:
   - Takes file path (`const char*`) and `llama_model_params`.
   - `llama_model_params` configures `n_gpu_layers` (Metal offloading), `use_mmap` (memory-mapped file reading), and `use_mlock` (pinning memory).
   - Returns an `OpaquePointer?` referencing `llama_model`. Returns `nil` on invalid or missing file.
2. **Context Creation (`llama_init_from_model`)**:
   - Takes `llama_model` pointer and `llama_context_params`.
   - `llama_context_params` sets `n_ctx` (context window size), `n_batch` (batch size), and `n_threads` (CPU thread allocation).
   - Returns `OpaquePointer?` referencing `llama_context`.
3. **Tokenization (`llama_tokenize`)**:
   - Converted UTF-8 prompt text into `[llama_token]` buffer using `llama_tokenize(vocab, text, len, tokens, max, add_special, parse_special)`.
4. **Batch Decoding (`llama_decode`)**:
   - Allocates `llama_batch` with `llama_batch_init(n_tokens, embd, n_seq_max)`.
   - Appends prompt and generated tokens into batch arrays (`batch.token`, `batch.pos`, `batch.seq_id`, `batch.logits`).
   - Evaluates logits via `llama_decode(context, batch)`. Returns 0 on success, non-zero on failure.
5. **Sampling Chain (`llama_sampler_chain_add` / `llama_sampler_sample`)**:
   - Initializes a sampler chain via `llama_sampler_chain_init(params)`.
   - Adds sampling strategies: `llama_sampler_init_greedy()`, `llama_sampler_init_temp(temp)`.
   - Samples next token from batch output logits using `llama_sampler_sample(sampler, context, batch.n_tokens - 1)`.
6. **Vocabulary EOG Check (`llama_vocab_is_eog`)**:
   - Evaluates whether sampled token matches End-Of-Generation (EOG / EOS) token.
7. **Token Piece Decoding (`llama_token_to_piece`)**:
   - Converts token ID to UTF-8 byte array (`[CChar]`) using `llama_token_to_piece(vocab, token, buf, len, lstrip, special)`.
8. **Resource Cleanup**:
   - Explicit, deterministic handle deallocation using `llama_sampler_free(sampler)`, `llama_free(context)`, `llama_model_free(model)`, and `llama_backend_free()`.

### Smallest Reusable Particles
- Native C API invocation chain (`llama_model_load_from_file` -> `llama_init_from_model` -> `llama_tokenize` -> `llama_decode` -> `llama_sampler_sample` -> `llama_free`).
- Sampler chain configuration and token-to-piece string decoding routines.

## 4. P1 Audit — llama-ios

**Source Pattern**: Community `llama-ios` runtime & model management particles

### Particle Analysis
1. **GGUF Import & Security-Scoped URL Handling**:
   - Calls `url.startAccessingSecurityScopedResource()` prior to reading external files selected via document pickers.
   - Wraps resource access in `defer { url.stopAccessingSecurityScopedResource() }`.
2. **Sandbox / App-Owned Storage Copying**:
   - Copies imported `.gguf` files into app-owned sandbox directory (`/ModelMetadata/Models/`) using `FileManager.default.copyItem(at:to:)`.
3. **Model Metadata Extraction**:
   - Header validation reading magic bytes `0x46554747` ("GGUF"), GGUF version (2 or 3), tensor count, metadata KV pair count, `general.architecture`, and `*.context_length`.
4. **Model Discovery & Selection**:
   - Enumerates files in app storage directory, reading index catalog `models_index.json` to construct list of available local model descriptors.
5. **Runtime Lifecycle & Residency**:
   - Single resident model enforcement ensuring existing model is unloaded before a new model is loaded into memory.
6. **Streaming Generation & Cancellation**:
   - `AsyncThrowingStream` emitting text deltas with `Task.isCancelled` checks.

### Smallest Reusable Particles
- Security-scoped URL access pattern (`startAccessingSecurityScopedResource` / `stopAccessingSecurityScopedResource`).
- Sandbox directory model import and file copying into dedicated app-owned folder.
- Model metadata index persistence (`models_index.json`).

## 5. P2 Audit — LocalLLMClient

**Source Pattern**: `LocalLLMClient` Swift boundary abstraction

### Particle Analysis
1. **Swift API Boundary**:
   - Decouples high-level Swift application callers from low-level native engine logic.
2. **Async / Streaming Abstraction**:
   - Wraps streaming inference in `AsyncThrowingStream<LocalModelStreamChunk, Error>`, converting native token pieces into typed text deltas.
3. **Cancellation & Error Propagation**:
   - Handles `Task.isCancelled` during token loop, throwing explicit errors (`LlamaCPPEngineError.cancelled`) and tearing down active task handles.
4. **Client / Runtime Separation**:
   - Caller interacts strictly through protocol contracts (`LocalModelEngine`, `LLMProvider`) without exposure to native C pointers or engine internals.

### Smallest Reusable Particles
- Clean protocol separation between caller (`LLMProvider`), adapter (`LocalModelProviderAdapter`), and native engine (`LocalModelEngine`).

## 9. Security & Data Boundary Audit

1. **Security-Scoped URL Lifecycle**:
   - When importing models from external directories, `url.startAccessingSecurityScopedResource()` MUST be called before reading file data or copying.
   - `defer { url.stopAccessingSecurityScopedResource() }` MUST be executed to prevent resource leaks or file lock contention.
2. **Sandbox Copying & App-Owned Storage**:
   - External files MUST be copied into app sandbox directory (`ProductPersistenceContainer.modelMetadataDirectoryURL/Models`).
   - App must never rely on persistent access to sandbox-external URLs which can be revoked by iOS at any time.
3. **Path Traversal Prevention & Filename Sanitization**:
   - Filenames from external URLs MUST be sanitized (strip `../`, path separators, invalid characters).
   - Resolved destination paths MUST be verified to lie strictly within `/ModelMetadata/Models/`.
4. **Duplicate Models & Deduplication**:
   - Re-importing an existing file checks file size and name to prevent creating duplicate disk copies.
5. **Corrupted Model Metadata**:
   - If `models_index.json` is corrupted, storage recovers by scanning `/ModelMetadata/Models/` and re-parsing `.gguf` headers.
6. **Stale Active-Model References**:
   - Active model ID in preferences is validated against disk storage before engine initialization. If missing, active selection is cleared.
7. **Safe Deletion of Active Models**:
   - Deleting a model currently loaded in memory calls `engine.unload()` prior to removing file from disk.
8. **Partial Import Failure Cleanup**:
   - If copying or header parsing fails mid-import, partially written destination files are immediately deleted.
9. **Oversized / Untrusted Model Files**:
   - Check available storage via `DeviceCapabilityProviding.availableStorageBytes`. Reject files exceeding available disk space.
10. **Unsupported GGUF Versions / Architectures**:
    - Reject non-GGUF files (magic != `0x46554747`) and unsupported versions (!= 2, 3) fail-closed.

## 10. Failure Analysis

| Failure Scenario | Boundary | Expected Behavior | Enforcement Mechanism |
|---|---|---|---|
| Malformed / non-GGUF file | Storage / Parser | Throw `GGUFParseError.invalidMagic` / fail closed | Magic byte check (`0x46554747`) |
| Corrupted tensor weights | Engine Load | Throw `LlamaCPPEngineError.nativeModelLoadFailed` | `llama_model_load_from_file` returns `nil` |
| Native eval decode error | Engine Stream | Throw `LlamaCPPEngineError.evalFailed` | `llama_decode` returns non-zero error code |
| Task cancellation during stream | Stream Loop | Cancel task, throw `cancelled` error | `Task.isCancelled` check in generation loop |
| Critical thermal state | Engine Stream | Abort generation, throw `thermalStateCritical` | `DeviceCapabilityProviding.thermalState` check |
| Critical memory pressure | Engine Stream | Halt generation, unload model, throw `memoryPressureCritical` | `DeviceCapabilityProviding.memoryPressure` check |
| Zero token chunks emitted | Engine / Adapter | Mark response as unverified / incomplete | `Executor Success != Verified Success` invariant |

## 11. Architectural Invariants

### 1. Identity Invariant
$$\text{Active Model Identity} == \text{Engine Model Identity}$$
`M8CompositionRoot.activeLocalModelEngine()` dynamically resolves the currently active `LocalModelDescriptor` from storage and instantiates `LlamaCPPModelEngine` with that exact identity.

### 2. Verification Invariant
$$\text{Executor Success} \neq \text{Verified Success}$$
An API execution returning zero chunks, empty text, or incomplete generation is NOT treated as successful inference. Real GGUF device inference remains UNVERIFIED until verified on hardware.

### 3. Failure Invariants
- **Malformed / Unsupported GGUF**: FAIL CLOSED.
- **Native Runtime Failure**: FAIL CLOSED.
- **Cancellation**: `CANCELLED != SUCCESS`. Stream terminates with cancellation error.

### 4. Lifecycle Invariant
App boot must NOT eagerly initialize the llama native runtime.
```text
App Boot
    ↓
CompositionRoot (Lightweight init)
    ↓
LocalModelStorage (Reads JSON metadata only)
    ↓
[User selects / imports active model]
    ↓
Active Model Descriptor
    ↓
LlamaCPPModelEngine (Instantiated lazily)
    ↓
engine.load(options:) [Invokes native llama_model_load_from_file]
    ↓
engine.generateStream(request:)
```

## 12. What MUST NOT Be Copied

PersonalAgent explicitly rejects and prohibits copying the following anti-patterns:

1. **Entire Sample Applications**: Do NOT copy view controllers, UI architectures, or application singletons from `examples/llama.swiftui` or `llama-ios`.
2. **Entire `llama-ios` Application Architecture**: PersonalAgent maintains its own clean `ProductPersistenceContainer` and `AgentSession` architecture.
3. **Duplicate Native llama.cpp Source Trees**: Do NOT import C/C++ source trees into `Sources/`. M8.1 already established `Frameworks/llama.xcframework` and `cllama`.
4. **Second XCFramework / Native Graph**: No secondary framework binaries or C library targets.
5. **Weak Linking & Linker Suppression**: Do NOT use `-undefined dynamic_lookup` or linker hacks.
6. **Arbitrary Compiler Defines**: No custom macros to suppress compiler warnings or native errors.
7. **Fake Inference & Stubs**: No mock token generators pretending to run GGUF models.
8. **Unnecessary Dependencies**: Zero external third-party Swift packages for model management.

## 14. Recommended Implementation Sequence

Based on this particle audit, the recommended implementation sequence for M8.2 is:

1. **Storage Layer**: Implement `FileBackedLocalModelStorage` in `PAProviders` (or `PAProvidersLocal`), providing `importModel`, `listModels`, `selectActiveModel`, `activeModel`, and `deleteModel`.
2. **Composition Integration**: Update `M8CompositionRoot` to accept `localModelStorage` and dynamically resolve `activeLocalModelEngine()`.
3. **UI Integration**: Expose GGUF import (`.fileImporter`), model list, selection, and local generation testing in `ProvidersScreen` / UI layer.
4. **Integration & Storage Tests**: Add `LocalModelStorageTests` verifying import, security-scoped URL handling, sandbox copying, index persistence, active selection, and cleanup.
