# M0 — Architecture Skeleton

## Objective

Create a buildable, testable, contract-driven repository for the iPhone 12 Pro Max Personal Agent client.

## In scope

- Swift package module boundaries
- Core contracts
- Dependency direction encoded and tested
- Test infrastructure
- SwiftUI shell with seven destination screens
- Honest M0 availability (no fake agent loop)

## Out of scope

- Kernel runtime (M1)
- Provider implementations (M2)
- Persistence / sync engines (M3)
- Memory engines (M4)
- Skill execution (M5)
- Tool execution (M6)
- Cognition loop (M7)
- Event replay (M8)
- Vertical slice (M9)
- Device hardening sign-off (M10)

## How to build

Contracts (Linux or macOS):

```
swift test
```

iOS app (macOS + Xcode 16+):

Open `PersonalAgent.xcodeproj`, destination iPhone 12 Pro Max.

## Contract test results

Swift 6.3.3 package tests: 23 tests / 5 suites passed.

iOS app compile and iPhone 12 Pro Max device matrix are Xcode-only. Not claimed PASS from this environment.
