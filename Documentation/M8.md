# M8 — Personal Agent Product Architecture Specification

Status: **M8 Product Architecture Foundation Specification Frozen & Verified.**

The M8 architecture transforms the existing M0–M7 Agent OS runtime into a client iOS Personal Agent product architecture.

---

## 1. Product Flow Architecture

```text
SwiftUI App
    ↓
App Session / App Lifecycle
    ↓
PAComposition (M8CompositionRoot)
    ↓
PAKernel (AgentRuntime / AgentSession)
    ↓
Cognition / Agency / Policy
    ↓
Provider / Memory / Skills / Modules
    ↓
Persistence / Device Services
```

- The SwiftUI App is strictly a **composition consumer**.
- The App must NOT become the `AgentRuntime`.
- `AgentRuntime` remains the sole authority over `AgentState` and goal status.

---

## 2. Layer & Boundary Specifications

### 2.1 App Runtime Boundary
- **Responsibility**: Application lifecycle, dependency boot (`M8CompositionRoot`), scene lifecycle, user-facing session ownership, and foreground/background transitions.
- **Rule**: Must not own or mutate `AgentState` directly.

### 2.2 Agent Session Boundary (`AgentSession`)
- **Responsibility**: Contract bridging user interaction and the `AgentRuntime`.
- **Contract Surface**:
  ```text
  user input → agent session → AgentRuntime → observation/result → UI
  ```
- **Invariants**: `AgentSession` wraps `AgentRuntime` and streams events without duplicating or storing a secondary copy of `AgentState`.

### 2.3 Provider Boundary
- **Responsibility**: Abstract LLM inference execution behind `LLMProvider` contracts (`PAProviders`).
- **Invariants**: The Kernel depends strictly on `LLMProvider` contracts. Concrete providers (`PAProvidersGrok`, `PAProvidersOpenAI`, `PAProvidersLocal`) exist as adapter targets.

### 2.4 Local Model Boundary (`LocalModelEngine`)
- **Responsibility**: Vendor-agnostic contract for on-device inference engines (MLX, llama.cpp, Core ML, Apple Foundation, GGUF).
- **Contract Surface**:
  - `LocalModelIdentity`: ID, name, parameterCount, quantization, contextTokenLimit.
  - `LocalModelAvailability`: `.notDownloaded`, `.downloading`, `.ready`, `.unsupported`, `.error`.
  - `LocalModelLifecycleState`: `.unloaded`, `.loading`, `.loaded`, `.unloading`, `.failed`.
  - `LocalModelLoadingOptions`, `LocalModelGenerationRequest`, `LocalModelStreamChunk`, `LocalModelResponse`.
  - `LocalModelEngine` protocol: `load`, `generate`, `generateStream`, `cancel`, `unload`.
- **Adapter Strategy**: `LocalModelProviderAdapter` wraps any `LocalModelEngine` implementation into an `LLMProvider`, allowing external technology particles to enter safely without modifying `PAKernel`.

### 2.5 Device Capability Boundary (`DeviceCapabilityProviding`)
- **Responsibility**: Framework-agnostic contracts for observing device capabilities (thermal state, memory pressure, network availability, application lifecycle, storage) without placing UIKit, SwiftUI, or Network.framework inside `PAKernel`.
- **Implementations**: `DefaultDeviceCapabilityProvider` for pure-Swift headless/testing environments and platform-specific monitors at the app boundary.

### 2.6 Product Persistence Boundary (`ProductPersistenceContainer`)
M7 durable execution persistence remains authoritative for Agent run lifecycle & recovery. M8 distinguishes product domain persistence into isolated folder hierarchies:
1. **Agent Durable State** (`/AgentDurableState`): M7 `RunStore`, `ExecutionAttemptStore`, `RunCheckpointStore`, `StateJournalStore`, `MutationEvidenceStore`. Authoritative for Agent lifecycle.
2. **Conversation / Session Data** (`/SessionData`): `SessionDataStore` for UI chat presentation history.
3. **Model Metadata** (`/ModelMetadata`): `ModelMetadataStore` for downloaded model inventory.
4. **App Preferences** (`/AppPreferences`): `AppPreferencesStore` for user settings and active provider choices.
5. **Credentials & Secrets** (`/Secrets`): `SecretStore` (`PASecurity`) for encrypted secrets. Secrets never enter `AgentState`, checkpoints, events, or logs.

## 3. External Technology Adapter Rule

External repositories and inference engines must conform to the adapter architecture:

```text
External Technology (MLX / llama.cpp / Core ML)
        ↓
Adapter (LocalModelEngine)
        ↓
PA Provider / Local Model Contract (LocalModelProviderAdapter → LLMProvider)
        ↓
PAComposition (M8CompositionRoot)
        ↓
AgentRuntime (PAKernel)
```

- External technology must NEVER become authoritative over `AgentState`.
- External code must NEVER be copied into `PAKernel`.

---

## 4. IPA Boundary & Build Pipeline

The architecture prepares for this eventual distribution flow:

```text
Package build (SwiftPM targets)
    ↓
iOS App target (App/PersonalAgent)
    ↓
Device build
    ↓
Archive
    ↓
Code signing
    ↓
IPA
    ↓
iPhone 12 Pro Max acceptance
```

- No credentials, signing certificates, or provisioning profiles are committed.
- The Kernel and package targets compile purely via SPM without Xcode dependencies.
