## PR #67 GGUF FILE URL HANDOFF FORENSIC AUDIT
=============================================
ROOT CAUSE:
In SwiftUI `.fileImporter` completion closure, spawning an asynchronous `Task` without calling `selectedURL.startAccessingSecurityScopedResource()` immediately before Task creation allowed iOS to invalidate security-scoped sandbox access permissions upon document picker dismissal before `importModel(from:)` executed on the async worker thread.

MINIMAL FIX:
1. Immediately call `selectedURL.startAccessingSecurityScopedResource()` inside `.fileImporter` completion closure synchronously before spawning `Task`, transferring resource access scope into the Task and releasing via `defer { selectedURL.stopAccessingSecurityScopedResource() }`.
2. Wrap external Open-In `.onOpenURL` handoff in `PersonalAgentApp.swift` with immediate `startAccessingSecurityScopedResource()` and deferred release.
