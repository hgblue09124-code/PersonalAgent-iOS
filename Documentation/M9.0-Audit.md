### Summary of Four Critical Forensic Audit Findings
1. **`DefaultReasoner` does not perform LLM inference:** Returns a fixed string; zero connection to `DynamicActiveProvider`.
2. **`KernelSession.submitGoal()` does not trigger orchestration:** Goal is stored as `.proposed` and execution halts.
3. **`M6Orchestrator.executeProposal()` executes internally:** Bypasses M7 `ExecutionBoundary`, lease consumption, and attempt tracking.
4. **Local model capability exists but is disconnected from agent path:** `LlamaCPPModelEngine` and `cllama` work in isolation, but no agent path invokes them during reasoning.

## 2. Agreed M9 Target Structure

The target M9 architecture establishes an end-to-end contract trace for a Real Local Agent:

```
[ User Task ]
      │
      ▼
[ Agent Runtime ] ──(Initiates Run)──> [ M6Orchestrator ]
                                              │
                                              ▼
                                    [ Reason / Decide ]
                                              │
                                              ▼
                                    [ Local LLM Provider ]
                                    (DynamicActiveProvider → LlamaCPPModelEngine)
                                              │
                                              ▼
                                    [ Action Proposal ]
                                    (Typed ToolID + Arguments)
                                              │
                                              ▼
                                    [ Action / Capability Boundary ]
                                    (ExecutionBoundary + CapabilityLease)
                                              │
                                              ▼
                                    [ Module Execution ]
                                    (ModuleRuntime → ToolModule → EchoTool)
                                              │
                                              ▼
                                    [ Observation Capture ]
                                    (ExecutionReceipt + Evidence Resolution)
                                              │
                                              ▼
                                    [ Agent Runtime ]
                                    (Authoritative StateUpdate)
                                              │
                                              ▼
                                   [ Next Step / Termination ]
```

### Component Ownership Breakdown

* **Agent Runtime Ownership:** `AgentRuntime` (`Sources/Core/Agent/AgentRuntime.swift:13`). Sole authority over `AgentState`, goal lifecycle transitions (`.proposed` → `.active` → `.completed` / `.aborted`), and event logging.
* **Reasoning Ownership:** `Reasoning` / `CognitionPipelining` (`Sources/Core/Cognition/CognitionContracts.swift`). Responsible for turning user context and observation history into structured prompts and evaluating model outputs.
* **Local LLM Inference Ownership:** `LLMProvider` / `DynamicActiveProvider` (`Sources/Composition/M8CompositionRoot.swift:122`) → `LocalModelProviderAdapter` (`Sources/Providers/Local/LocalModelAdapter.swift:6`) → `LlamaCPPModelEngine` (`Sources/Providers/Local/LlamaCPPModelEngine.swift:10`). Responsible for GGUF model execution, streaming token generation, and thermal/memory governance.
* **Action Proposal Ownership:** `Planning` & `Executing` (`Sources/Core/Cognition/CognitionContracts.swift`). Responsible for parsing structured LLM output into typed `ActionProposal` instances with explicit `ToolID` and payload arguments.
* **Action Execution Ownership:** `ExecutionBoundary` (`Sources/Core/Agent/ExecutionBoundary.swift:105`) delegating to `ModuleRuntime` (`Sources/Modules/Contracts/ModuleRuntime.swift:12`). Enforces policy evaluation, approval gates, atomic `CapabilityLease` step consumption, and `STARTED_UNKNOWN` attempt persistence.
* **Observation Ownership:** `ExecutionBoundary` (`Sources/Core/Agent/ExecutionBoundary.swift:230`) and `M6Orchestrator` (`M6Orchestrator.swift:340`). Captures execution output fields, resolves target evidence, and produces immutable `Observation` records.
* **Loop State Ownership:** `M6Orchestrator` (`Sources/Core/Agent/M6Orchestrator.swift:120`). Manages cognitive cycle iteration and feeds prior cycle observations back into context assembly.
* **Termination / Max-Step Ownership:** `M6Orchestrator` (`maxCycles` limit) & `ExecutionBoundary` / `CapabilityLease` (`lease.maxSteps`).
* **Failure Propagation Ownership:** Fail-Closed policy enforced across `ExecutionBoundary`, `M6Orchestrator`, and `AgentRuntime`.

## 3. Current → Target Gap Analysis

### Gap 1: Agent Goal Submission to Orchestration Trigger
* **Current:** `KernelSession.submitGoal()` → `DefaultAgentSession.submitInput()` → `AgentRuntime.submit(goal:)` stores goal as `.proposed` and halts.
* **Target:** Goal submission transitions goal to `.proposed` and triggers `M6Orchestrator.run(goalID:)` via a bound execution trigger.
* **Missing Contract:** `AgentGoalOrchestrating` / `RunTriggering` seam connecting goal activation to orchestrator run.
* **Why Current Cannot Satisfy M9:** Goals submitted via UI remain in `.proposed` state forever without execution.
* **Smallest Architectural Change:** Add an optional `orchestrator` execution trigger to `AgentSession` or `AgentRuntime` that initiates `M6Orchestrator.run(goalID:)` upon goal submission.

### Gap 2: Reasoner to Local LLM Inference Bridge
* **Current:** `DefaultReasoner` returns static string `"Reasoned for \(rawInput)"` without referencing any provider.
* **Target:** `LLMReasoner` invokes `coordination.provider` (`DynamicActiveProvider`) with structured system prompts, user context, and tool schemas.
* **Missing Contract:** `LLMReasoningCodec` / `LLMStructuredOutputParser` bridging `LLMRequest`/`LLMResponse` to structured reasoning decisions.
* **Why Current Cannot Satisfy M9:** The agent never queries the LLM; local GGUF models are completely idle during goal processing.
* **Smallest Architectural Change:** Implement `LLMReasoner: Reasoning` that calls `LLMProvider.complete()` via `KernelCoordinationBoundary` and parses decisions.

### Gap 3: LLM Output to Typed Action Proposals
* **Current:** `DefaultProposer` outputs proposals with `toolID == nil`.
* **Target:** `LLMProposer` extracts typed `ToolID` (e.g. `ToolID("echo")`) and structured arguments from LLM response.
* **Missing Contract:** Structured tool invocation schema codec for GGUF model responses.
* **Why Current Cannot Satisfy M9:** No mechanism exists to convert text generated by GGUF into executable tool calls.
* **Smallest Architectural Change:** Implement structured output parser that converts model text into `ActionProposal(toolID: ToolID("echo"), description: arguments)`.

### Gap 4: Orchestrator Proposal Execution to ExecutionBoundary
* **Current:** `M6Orchestrator.executeProposal` calls `moduleRuntime.execute` directly, bypassing M7 execution governance.
* **Target:** `M6Orchestrator` delegates proposal execution to `ExecutionBoundary.executeProposal()`.
* **Missing Contract:** Direct delegate connection from `M6Orchestrator` to `ExecutionBoundary`.
* **Why Current Cannot Satisfy M9:** Bypasses `CapabilityLease`, idempotency keying, `ExecutionAttempt` persistence (`.startedUnknown`), and `resolveEvidence()`.
* **Smallest Architectural Change:** Update `M6Orchestrator` to invoke `ExecutionBoundary.executeProposal()` when `ExecutionBoundary` is present in composition.

## 4. Failure Boundaries: Current vs. Target

| Failure Scenario | Current Behavior (origin/main) | Target M9 Contract |
| :--- | :--- | :--- |
| **No Active Model Selected** | `DynamicActiveProvider` falls back silently to `DeterministicFakeProvider`. Goal succeeds on fake provider output. | `DynamicActiveProvider` returns `noActiveModel` / throws `modelNotFound`. Agent loop halts, recording `GoalStatus.blocked`. |
| **Invalid GGUF File Header** | `LlamaCPPModelEngine.load()` fails with `GGUFParseError`. State becomes `.failed`. Uncaught by `DefaultReasoner`. | Engine transitions to `.failed`. `LLMProvider` throws `unavailable`. `M6Orchestrator` aborts goal to `GoalStatus.blocked`. |
| **Native Model Load Failure** | `LlamaCPPModelEngine.load()` throws `nativeModelLoadFailed`. State becomes `.failed`. | Engine transitions to `.failed`. Runtime captures failure, records `RunRecord.interrupted` and `GoalStatus.blocked`. |
| **Inference Failure (Thermal/Memory)**| `LlamaCPPModelEngine` throws `thermalStateCritical` or `memoryPressureCritical`. | Stream terminates with explicit error. Agent captures failure, aborts cycle, and transitions goal to `GoalStatus.blocked`. |
| **Malformed LLM Output** | Unhandled (DefaultReasoner never queries LLM). | `LLMStructuredOutputParser` throws `malformedOutput`. `M6Orchestrator` produces `Observation(succeeded: false)` and aborts loop. |
| **Invalid / Unregistered Action** | `M6Orchestrator` produces `Observation(succeeded: false)` with summary `"Execution target unavailable"`. | `ExecutionBoundary` rejects pre-dispatch. `ExecutionAttempt` saved as `.failed`. Goal state updated to `.aborted`. |
| **Action Execution Failure** | `ModuleRuntime` returns `ModuleResult(state: .failed)`. `M6Orchestrator` sets `succeeded = false`. | `ExecutionBoundary` records receipt and verifies evidence. Evaluator returns `.abort`. StateUpdate sets `GoalStatus.aborted`. |
| **Observation Contradiction** | Unhandled (No independent evidence resolution in M6Orchestrator). | `ExecutionBoundary.resolveEvidence()` detects contradiction. Attempt set to `.unresolved`. Goal set to `GoalStatus.blocked`. |
| **Max-Step / Cycle Exhaustion** | `M6Orchestrator` halts when `cycleCount >= maxCycles`, returning final evaluation. | `M6Orchestrator` or `CapabilityLease` step exhaustion triggers Evaluator `.abort("Max cycles reached")`. Goal set to `GoalStatus.aborted`. |
| **Runtime / Provider Failure** | `AgentRuntime` throws `KernelError`. Goal remains in prior state. | `AgentRuntime` catches error, records failure event, applies fail-closed `StateUpdate`, or transitions to `AgentLifecycle.failed`. |

## 5. M9 Implementation Gates (Future Stages)

These gates represent the sequential implementation milestones for M9. **None of these gates are implemented in this audit PR.**

### Gate M9.1 — Real GGUF Execution
* **Purpose:** Verify that complete and stream requests route through `LlamaCPPModelEngine` to produce text from a real loaded GGUF model file via native `cllama`.
* **Required Contract:** `LocalModelEngine` (`LlamaCPPModelEngine.swift:10`) & `LLMProvider` (`LocalModelAdapter.swift:6`).
* **Exact Code Boundary:** `Sources/Providers/Local/LlamaCPPModelEngine.swift:150` & `Sources/Providers/Local/LocalModelAdapter.swift:42`.
* **Expected Implementation Change:** Ensure `DynamicActiveProvider` completes requests using native GGUF token generation when a model is loaded.
* **Tests:** `Tests/PersonalAgentTests/M91RealGGUFExecutionTests.swift`.
* **Evidence Required:** Non-empty text delta generation with `finishReason == "stop"` from a valid GGUF file.
* **Acceptance Condition:** Native `cllama` execution produces valid tokens without fallback or stubbing.

### Gate M9.2 — Agent Execution Contract
* **Purpose:** Connect `M6Orchestrator` reasoning phase to `DynamicActiveProvider` and bind goal submission to orchestrator execution.
* **Required Contract:** `Reasoning` (`CognitionContracts.swift`) & `AgentSession` (`AgentSession.swift`).
* **Exact Code Boundary:** `Sources/Core/Agent/M6Orchestrator.swift:37` & `App/PersonalAgent/KernelSession.swift:55`.
* **Expected Implementation Change:** Replace `DefaultReasoner` with `LLMReasoner` that calls `LLMProvider` and bind `AgentSession.submitInput()` to trigger `M6Orchestrator.run()`.
* **Tests:** `Tests/PersonalAgentTests/M92AgentExecutionContractTests.swift`.
* **Evidence Required:** Audit log proving `M6Orchestrator` invoked `LLMProvider` during reasoning and generated a decision.
* **Acceptance Condition:** Goal submission automatically triggers LLM-backed reasoning loop.

### Gate M9.3 — Action / Observation
* **Purpose:** Route action proposal execution through `ExecutionBoundary` using `ToolModule(tool: EchoTool())`.
* **Required Contract:** `ExecutionBoundary` (`ExecutionBoundary.swift:105`) & `ToolModule` (`ToolModule.swift:6`).
* **Exact Code Boundary:** `Sources/Core/Agent/M6Orchestrator.swift:293` & `Sources/Core/Agent/ExecutionBoundary.swift:105`.
* **Expected Implementation Change:** `M6Orchestrator` delegates action execution to `ExecutionBoundary.executeProposal()`, creating `CapabilityLease` and `ExecutionAttempt`.
* **Tests:** `Tests/PersonalAgentTests/M93ActionObservationTests.swift`.
* **Evidence Required:** Event log containing `ExecutionAttempt` (`.startedUnknown` → `.completed`), `ExecutionReceipt`, and `Observation` for `mod.echo`.
* **Acceptance Condition:** Action execution is fully governed by `ExecutionBoundary` and M7 durable store.

### Gate M9.4 — Closed Agent Loop
* **Purpose:** Demonstrate a complete end-to-end cognitive loop: Task → Reason (LLM) → Proposal → Action (`EchoTool`) → Observation → StateUpdate (`.completed`).
* **Required Contract:** `M6Orchestrator` (`M6Orchestrator.swift:120`) & `AgentRuntime` (`AgentRuntime.swift:214`).
* **Exact Code Boundary:** `Sources/Core/Agent/M6Orchestrator.swift:120` & `Sources/Core/Agent/AgentRuntime.swift:214`.
* **Expected Implementation Change:** Connect multi-step cycle feedback loop with authoritative `StateUpdate` and `maxCycles` enforcement.
* **Tests:** `Tests/PersonalAgentTests/M94ClosedAgentLoopTests.swift`.
* **Evidence Required:** Complete event log trace: `.perceptionReceived` → `.contextBuilt` → `.planProduced` → `.actionProposed` → `.actionAuthorized` → `.actionExecuted` → `.observationProduced` → `.evaluationCompleted` → `.stateUpdated` (`targetStatus: .completed`).
* **Acceptance Condition:** End-to-end loop completes autonomously and updates goal status to `.completed`.

### Gate M9.5 — Physical Device Proof
* **Purpose:** Verify the complete closed agent loop executing on target physical iPhone 12 Pro Max hardware.
* **Required Contract:** Full M9 composition stack running inside iOS application sandbox.
* **Exact Code Boundary:** `App/PersonalAgent/KernelSession.swift` & `Sources/Composition/M8CompositionRoot.swift`.
* **Expected Implementation Change:** Load a real GGUF model in app sandbox on device, submit goal, run local inference, execute `EchoTool`, and reach `.completed` state.
* **Tests:** Xcode Physical Device Test Runner / `M95PhysicalDeviceIntegrationTests.swift`.
* **Evidence Required:** Console/XCTest audit log from physical iPhone 12 Pro Max running iOS 18+ demonstrating local GGUF load, GPU/CPU inference, tool execution, observation return, and goal completion.
* **Acceptance Condition:** Verified physical device sign-off without mocks or desktop fallbacks.
