* **Agent Runtime Location:** `AgentRuntime` in `Sources/Core/Agent/AgentRuntime.swift:13` conforming to `AgentRuntimeCoordinating`, `AgentLifecycleManaging`, and `GoalManaging`.
* **Boundary Rules:**

## 5. Failure & Propagation Matrix

M9 must fail closed across all failure modes:

| Failure Mode | Failure Source Symbol | Owner | Propagation Path | Final Agent / Goal State |
| :--- | :--- | :--- | :--- | :--- |
| **Missing Active Model** | `LocalModelRuntimeCoordinator` (`M8CompositionRoot.swift:34`) | `DynamicActiveProvider` | Throws `modelNotFound` → `Reasoning` fails → `M6Orchestrator` aborts | `GoalStatus.blocked` / `.aborted` |
| **Invalid GGUF Header** | `GGUFModelParser` (`GGUFModelParser.swift:15`) | `LlamaCPPModelEngine` | Throws `invalidMagic` / `unsupportedVersion` → Engine state `.failed` → Provider unavailable | `GoalStatus.blocked` / `.aborted` |
| **Native Model Load Failure** | `LlamaCPPModelEngine` (`LlamaCPPModelEngine.swift:120`) | `LlamaCPPModelEngine` | Throws `nativeModelLoadFailed` → Engine state `.failed` → Provider unavailable | `RunRecord.interrupted` / `GoalStatus.blocked` |
| **Inference Failure (Thermal/Memory)** | `LlamaCPPModelEngine` (`LlamaCPPModelEngine.swift:195`) | `LlamaCPPModelEngine` | Throws `thermalStateCritical` / `memoryPressureCritical` → Stream finishes with error | `RunRecord.interrupted` / `GoalStatus.blocked` |
| **Action Execution Failure** | `ModuleRuntime` / `ToolModule` (`ToolModule.swift:25`) | `ExecutionBoundary` | `ModuleResult(state: .failed)` → `Observation(succeeded: false)` → Evaluator returns `.abort` | `GoalStatus.aborted` |
| **Malformed LLM Output** | `LLMStructuredOutputParser` | `Reasoning` | Parser throws `malformedOutput` → `Observation(succeeded: false)` → Evaluator returns `.abort` | `GoalStatus.aborted` |
| **Invalid / Unregistered Action** | `ExecutionBoundary` (`ExecutionBoundary.swift:110`) | `ExecutionBoundary` | Pre-dispatch capability/catalog check fails → `Attempt.status = .failed` → `Observation(succeeded: false)` | `GoalStatus.aborted` |
| **Observation Failure / Contradiction** | `ExecutionBoundary` (`ExecutionBoundary.swift:220`) | `ExecutionBoundary` | Evidence resolution returns `.unknown` / `.unavailable` → Attempt `.unresolved` / `.startedUnknown` | `RunRecord.interrupted` / `GoalStatus.blocked` |
| **Max-Step Exhaustion** | `M6Orchestrator` (`M6Orchestrator.swift:140`) / `CapabilityLease` | `M6Orchestrator` | `cycleCount >= maxCycles` or lease exhausted → Evaluator returns `.abort("Max cycles reached")` | `GoalStatus.aborted` |
| **Runtime / Provider Failure** | `ProviderRuntime` / `AgentRuntime` | `AgentRuntime` | `KernelError` / `ProviderRuntimeError` thrown → `applyStateUpdate` or command rejection | `GoalStatus.aborted` / `AgentLifecycle.failed` |

## 8. Forbidden Shortcuts Verification

The M9 design strictly avoids the following anti-patterns:

* [x] **NO "Model generated text" treated as Agent success:** LLM text is an intermediate cognitive step. Agent completion requires action execution, observation capture, and authoritative `StateUpdate`.
* [x] **NO Mocked inference as final evidence:** M9.5 physical device proof requires real GGUF weights and native `cllama` execution.
* [x] **NO UI directly calling llama.cpp:** UI interacts strictly via `AgentSession`. UI never touches `cllama` or `LlamaCPPModelEngine`.
* [x] **NO Bypassing the Agent runtime:** `AgentRuntime` remains the sole authority for state and goal lifecycles.
* [x] **NO Parallel model/provider registries:** Uses existing `LocalModelStorage`, `LocalModelRuntimeCoordinator`, and `DynamicActiveProvider`.
* [x] **NO Oversized Skills infrastructure:** Uses existing atomic `EchoTool` / `ToolModule` / `ModuleCatalog`.
* [x] **NO Unnecessary UI rewrite:** Existing SwiftUI screens and `KernelSession` remain intact.
* [x] **NO Unnecessary architecture rewrite:** Builds directly on M6 (`M6Orchestrator`), M7 (`ExecutionBoundary`, `RunLifecycleManager`), and M8 (`M8CompositionRoot`, `DynamicActiveProvider`).
* [x] **NO Removing failure paths for green tests:** Fail-closed policy enforced across all 10 failure modes.

## 9. Risks & Unresolved Questions

1. **Local GGUF Prompt Formatting & Structured Output Reliabilty:** Small 1B–3B local GGUF models on mobile devices may occasionally generate malformed JSON for tool calls. M9 must enforce strict fail-closed parsing with clear error observations.
2. **Memory Limits on iPhone 12 Pro Max (6GB RAM):** Models larger than ~3GB may trigger iOS memory pressure (`memoryPressureCritical`). `LlamaCPPModelEngine` auto-unload governance must be validated under load.
3. **Loop Binding Trigger:** Currently, submitting a goal puts it in `.proposed` state. M9 needs an explicit, safe trigger mechanism to start orchestration without violating `AgentRuntime` state invariants.
